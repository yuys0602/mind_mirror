内生安全实验报告：从语气探针到拟态裁决

引子：一份会自曝其短的报告

这份报告记录我们在单卡 80GB GPU 上用两个开源模型完成的三组最小化实验，目标只有一个：验证内生安全的方法论在 LLM 上是否成立。我们把失败的实验迭代也一并公开——因为安全研究里最贵的不是算力，而是对数字的过度自信。方法可复现，数字诚实报告，这是一份"会自曝其短"的报告，也正是我们敢把"内生安全"写进品牌承诺的原因：可信来自可复现，可复现来自诚实。

实验平台与三条实验线

三组实验共用一套平台：单卡推理、无 API 依赖，任何团队都能按同一方法复现。三条实验线分别对应心镜产品方法论的三个支柱：

  • 语气探针：内部状态是否编码语气信息——对应"白盒观测"。
  • 谎言方向探针：内部状态是否先于输出携带谎言信息——同样对应"白盒观测"，但检验的是更高层的语义。
  • 异构裁决：DHR 行为层构造是否买回真实安全增益——对应"异构裁决"。

    • 三条线的共同设计原则：所有结论都来自配对对比而非绝对评分，所有探针都在训练集之外的任务上检验，所有数字都区分"拦截"与"交付"。

方法论的四次迭代：失败是方法的一部分

最终的三个数字背后，是四个版本的实验方法，每一次迭代都由一次失败驱动。这些失败值得写出来，因为它们比成功更能说明方法的质量。

  • v1，单分裁判饱和。第一版语气实验让 LLM 裁判对样本质量打 1-10 分，结果裁判把几乎所有样本都打 8/9 分——量表饱和，没有区分度。修正：改为两两对决（pairwise），让裁判在两者之间强制选择，区分度立刻出现。绝对评分是 LLM 裁判最舒服、也最不可信的姿势；相对选择才是它的可靠工作区间。
  • v2，随机划分过拟合。第一版探针按随机划分切分训练与测试集，测试集过小（6 个），且同一任务可能同时出现在两边——探针可能在记忆提示词的表面特征，而不是"语气"这个语义。修正：改为跨任务划分（8 个任务训练 / 2 个任务测试），探针必须在从未见过的任务上判别语气，才能说明内部状态编码的是语气本身。这一改，直接改变了结论的强度：从"记住了几个样例"变成"学会了语气这个语义"。
  • v2，跨模型维度不齐。Qwen 的隐藏状态是 4096 维，Llama 是 3584 维，无法直接拼接或投影到公共空间。修正：各模型先做 PCA-512 投影，再在 512 维公共空间对齐。维度不齐是跨模型研究的日常，不值得抱怨，值得工程化。
  • v3，信号不在主方差方向。PCA-512 投影后，语气判别准确率掉到 0-25%——语气信号不在主方差方向上，被主成分投影丢掉了。修正：改为配对对比设计——对同一任务采集"情绪态 − 中性态"的差异向量，信号稳定地浮现出来。这次失败教给我们一个更深的东西：语义信号不一定住在方差最大的方向上，盯着主成分找信号，可能找错了地方。
  • v3，裁判位置偏置。Llama 当裁判时永远选择第一个候选——位置偏置淹没了真实差异。修正：统一由 Qwen 担任裁判，且每对样本正反序各判一次，两次一致才算胜。位置偏置是 LLM 裁判最常见也最隐蔽的系统性误差，双序一致是它的标准解。
  • v4，指标定义修正。异构裁决实验最初把"三路全部违规、被裁决层拦截"错计为攻击成功，稀释了防御的数字。修正：明确 ASR 定义——拦截即防御成功，攻击成功特指不安全输出被实际交付。指标定义决定了实验在测量什么：拦下来的是防御的胜利，还是攻击的失败？我们把这条界线画清楚，数字才有意义。
这四次迭代体现的不是聪明，而是安全研究的基本纪律：当数字好得可疑时，先怀疑方法，再怀疑结论。

结果一：语气探针

配对对比探针在跨任务划分下，Qwen 与 Llama 各自的语气判别准确率均达 100%；双模型池化后 80%。同时测量行为效应：双序一致的两两对决裁判下，礼貌与要挟的胜出率仅 20% 与 10%。诚实地说，在 7B 级模型上，语气对行为的效应弱而不稳定——这与文献中旗舰模型的显著行为效应（EmotionPrompt 相对提升 8%、Mind Your Tone 中 Very Rude 84.8% 对 Very Polite 80.8%）形成对照。

但这个对照本身是一条发现：内部痕迹先于行为效应出现，观测层比行为层更早、更稳定地携带语义信息。语气没有显著改变行为，却稳定地改变了内部状态——安全监测应该站在观测层，而不是等行为已经变坏。这正是心镜"白盒观测"路线的实验依据：行为会撒谎，内部状态更难撒谎。

结果二：谎言方向探针

对同一陈述分别采集"诚实态"与"撒谎态"的内部状态，学习两者之差的方向。该方向在模型间通用：跨模型迁移准确率 93.3%——存在跨架构的共性谎言方向。同模型 holdout 因小样本（12 对）仅约 50%，如实标注、待扩大样本。

这条结果与文献路线一致：Azaria 与 Mitchell 从隐藏层激活分类真假陈述（71-83%），CCS 无监督寻找真值方向；我们把"真假知识"探针推进到"撒谎行为"方向，且证明了方向的可迁移性。内部状态先于输出携带谎言信息——这给了"心口检测"一个可工程化的基座：跨模型共性的谎言方向意味着，训练监测器不必依赖某一个特定模型的内部几何。

结果三：异构裁决

对同一组提示注入攻击，比较三种构造：单模型注入成功率 80%；同构 3 表决同为 80%——同一漏洞击穿全部同构副本，共同失效使冗余毫无增益，这是 Knight 与 Leveson 对 N 版本程序设计批评的现场复现，也是相对正确公理的反面教材；异构 3 路加分层裁决把攻击交付率压至 0%，其中 66.7% 的场景三路全部违规、被直接阻断，良性任务误报 0%。

同构冗余的 80% 不是失败，它是异构必要性的证明：安全增益来自异构构造，而非表决本身。

这条结果的剂量-响应结构很干净：同样的裁决协议，换掉执行体的异构度，攻击交付率从 80% 到 0%。它同时验证了两件事：其一，相对正确公理的前提（执行体真的异构）必须被度量而不是被假定；其二，异构构造一旦成立，裁决就能把攻击交付率压到可承诺的水平。

局限与下一步

局限必须说清：数据规模小、攻击面窄；探针在分布外输入上的鲁棒性未验证；两个模型均为 7-8B 级开源模型，结论外推到商业级模型有待检验；裁判分存在模型自评偏差。下一步：扩大攻击样本与多轮智能体场景，引入更多模型家族，把探针与裁决接入真实产品链路，并用激活方向操控（steering）检验语气回路的因果性——把"相关"升级为"因果"。

诚实地说，这份报告的每一组数字都还不足以支撑任何产品宣称。它们支撑的是一件事：方法论可行。白盒观测看得见信号，异构裁决压得下交付率，配对对比给得出可复现的数字。这三件事成立，产品的路才能往下走。

心镜视角：从方法论可行性到产品

心镜的产品路线基于同一方法论：白盒观测、异构裁决、负反馈进化。先用最小系统证明它有效，再在工程中放大它——这个顺序不会变。下一次报告会更好，不是靠数字更漂亮，而是靠方法更扎实。安全产品的信任从来不是买来的，是一次一次把失败与修正如实写出来，攒出来的。
